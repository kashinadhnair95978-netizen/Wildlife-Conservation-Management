# Wildlife Conservation Management System


![Wildlife Conservation Banner](https://images.unsplash.com/photo-1534759846116-5799c33ce22a?auto=format&fit=crop&w=2400&q=80)

A modern, full-featured **Wildlife Conservation Management System** built with **React**, **TypeScript**, and **Vite**. This application provides a centralized platform to monitor, track, and manage wildlife conservation efforts including species, animals, habitats, protected areas, threats, incidents, rescue operations, and more.

## Features

### Core Management
- **Species Registry** - Comprehensive database of monitored species with classification details
- **Animal Tracking** - Individual animal profiles with health status, population data, and movement history
- **Habitat Management** - Track and monitor different habitat types and their conditions
- **Protected Areas** - Manage national parks, sanctuaries, and conservation zones across multiple states

### Field Operations
- **Sighting Records** - Log and verify wildlife sightings with timestamps, locations, and observer details
- **Incidents & Threats** - Report poaching, forest fires, human-wildlife conflicts with severity tracking
- **Rescue Operations** - Coordinate end-to-end rescue missions from distress calls to rehabilitation and release
- **Animal Health** - Track examinations, treatments, vitals, and medical history

### Analytics & Administration
- **Dashboard** - Real-time overview with interactive charts, statistics, and activity feeds
- **Reports & Analytics** - Generate insights on population trends, threat patterns, and conservation impact
- **Ranger Workforce** - Manage patrol assignments, teams, and field personnel
- **Conservation Activities** - Track ongoing programs, projects, and their outcomes


## Tech Stack

- **Frontend Framework**: [React 19](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: In-memory CRUD store with service layer
- **Linting**: [Oxlint](https://oxc.rs/docs/guide/linter.html)
